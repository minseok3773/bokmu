# 복무요원 복무상황부

정신재활시설에서 사회복무요원의 근태를 정리하는 도구입니다.

**주소: https://minseok3773.github.io/bokmu/** (로그인 없이 씀)

## 하는 일

- 사회복무포털 근태현황을 캡처해 넣거나 표를 복사해 붙여 넣으면, 요원별 달력이 채워집니다.
- 요원별 **일일 복무 상황부**(A4 가로, 시설 종이 양식과 같은 모양)를 인쇄용 파일로 만듭니다.
- **보수명세서 근무상황** 숫자(출근일수, 연가일수, 30일 이내 병가일수, 교육일수, 복무이탈일수, 연가초과 결근일수, 30일초과 병가일수)를 계산해 복사할 수 있습니다.
- 요원별 1일 교통비를 넣으면 이번 달 교통비와 합계를 보여 줍니다.
- 포털 합계와 달력이 다르면 "포털과 다름"으로 알려 줍니다.
- **사회복무요원 일일 관찰일지**를 시설 양식과 같은 모양(A4 가로)으로 만듭니다. 그날 연가·병가인 요원은 출근·퇴근 "-"와 휴가 이름이 자동으로 들어가고, 출근한 요원은 배치부서·근무내용 기본값과 "- 특이사항 없음"이 들어갑니다. 하루치 또는 한 달 평일 전부를 한 파일로 내려받아 인쇄합니다. 한 달치를 **한글 파일(.hwpx)**로도 내려받을 수 있습니다(시설에서 쓰는 한글 양식과 같은 모양, 날마다 한 쪽).

## 알아둘 점

- **기록은 이 컴퓨터의 이 브라우저에만 저장됩니다.** 서버로 보내지 않습니다. 다른 컴퓨터에서는 보이지 않으니, 가끔 "기본값·백업·바탕화면 → 백업 파일 저장"으로 백업해 두세요.
- 캡처한 그림은 **이 컴퓨터 안에서** 글자를 읽습니다(AI를 쓰지 않음). 처음 한 번은 글자 인식 도구를 내려받느라 10~20초 걸립니다. 글자 인식은 틀릴 수 있으니 "포털과 같음" 표시를 확인하세요.
- 계산 규칙(특별휴가는 연가일수에 넣음, 공무상병가는 30일 이내 병가에 넣음 등)은 2026년 10월 시설 서류에 맞춘 것입니다. 기관 지침이 바뀌면 확인이 필요합니다.
- 공휴일은 2025~2027년만 들어 있습니다. 틀린 날은 달력에서 직접 고치세요.
